# Stadium Aura Aura Macro

Aura is a 70 ms smoothed multi-stage macro. It contributes tube drive, saturation, transformer color, glue/compression, de-harsh polish, width, and automatic negative gain compensation.

The Sweet Zone display uses input peak, actual compressor GR, limiter GR, tube activity, and output headroom:

- LOW: insufficient level/color activity for the intended effect
- SWEET: controlled color with headroom and limited limiter action
- HOT: high color/GR or reduced output headroom

Aura never exists solely as a loudness control.
