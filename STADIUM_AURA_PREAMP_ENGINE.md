# Stadium Aura Preamp Engine

- 73 Vintage Iron: broad low-mid density, controlled top rounding, asymmetric transformer-like saturation.
- API Punch: tighter bass, forward mids, modest odd-harmonic edge.
- Avalon Clean: low nonlinear density, broad cleanup and polished presence.

`preampDrive` scales color and uses output compensation. These are original voicings and not exact hardware models.
