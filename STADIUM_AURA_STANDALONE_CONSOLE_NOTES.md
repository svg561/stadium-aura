# Stadium Aura Standalone Console Notes

The JUCE Standalone wrapper provides device selection, sample rate, buffer size, channel routing, and live input/output. Stadium Aura supplies the processing, input/output gain, meters, presets, bypass, mono, limiter, and dim.

Use headphones or a feedback-safe monitor path for live microphones. The Standalone app cannot be inserted in Pro Tools; Pro Tools requires AAX.
