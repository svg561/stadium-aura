# Stadium Aura Tube Engine

Six original transfer families are provided: Clean Triode, Warm Triode, Hot Triode, Vintage Pentode, Big Bottle, and Cream Opto Tube. Each changes drive scale, asymmetry, harmonic balance, rounding, and compensation.

Tube glow is derived from real post-tube peak and tube drive. High quality uses the existing 2x interpolated color path. True filter-based oversampling and Ultra 4x/8x are TODO.
